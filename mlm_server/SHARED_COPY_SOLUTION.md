# Решение проблемы с модулем shared

## Проблема

Ошибка: `ModuleNotFoundError: No module named 'shared'`

Это происходило, потому что `shared` находится на уровень выше `mlm_server`, и когда Root Directory = `mlm_server`, Railway не может найти модуль.

## Решение

**Скопирован модуль `shared` внутрь `mlm_server/`**

Теперь структура:
```
mlm_server/
├── shared/          # Скопирован сюда
│   ├── api_client/
│   ├── models/
│   └── utils/
├── mlm/
├── mlm_server/
└── ...
```

## Преимущества

1. ✅ **Независимость** - MLM сервер не зависит от структуры корня проекта
2. ✅ **Простота** - не нужно настраивать PYTHONPATH
3. ✅ **Надежность** - модуль всегда доступен
4. ✅ **Совместимость** - работает с Root Directory = `mlm_server`

## Важно

- Модуль `shared` скопирован, а не перемещен
- Оригинальный `shared` в корне проекта остается для других серверов
- Если нужно обновить `shared`, обновите его в обоих местах

## Настройка в Railway

1. **Root Directory**: `mlm_server` (как и было)
2. **Start Command**: автоматически из `nixpacks.toml` или `railway.json`
3. **Переменные окружения**: как обычно

## Проверка

После копирования:
- ✅ Модуль `shared` должен быть найден
- ✅ Ошибка `ModuleNotFoundError` должна исчезнуть
- ✅ Сервер должен запуститься
