# Логика MLM Server $30

## Описание

При регистрации нового партнера (оплата $30) происходит следующее:

### Распределение $30:

1. **$15** → Желтый бонус рефереру
2. **$15** → Зеленый бонус рефереру

**Итого:** Реферер получает **$30** за каждого нового партнера.

## Пример

1. Пользователь A приглашает пользователя B
2. Пользователь B регистрируется и платит $30
3. Пользователь A получает:
   - $15 (желтый бонус)
   - $15 (зеленый бонус)
   - **Всего: $30**

## Настройки

```python
MLM_PARTNER_PRICE = 30.0    # Цена за статус партнера
MLM_YELLOW_BONUS = 15.0     # Желтый бонус
MLM_GREEN_BONUS = 15.0      # Зеленый бонус
```

## Отличия от сервера $100

- Сервер $100: сложная система зеленых/красных бонусов
- Сервер $30: простая система - фиксированные $15 желтый + $15 зеленый за каждого партнера
