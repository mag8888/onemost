# Логика MLM Server $20

## Описание

При регистрации нового партнера (оплата $20) происходит следующее:

### Распределение $20:

1. **$10** → Желтый бонус рефереру
2. **$10** → Зеленый бонус рефереру

**Итого:** Реферер получает **$20** за каждого нового партнера.

## Пример

1. Пользователь A приглашает пользователя B
2. Пользователь B регистрируется и платит $20
3. Пользователь A получает:
   - $10 (желтый бонус)
   - $10 (зеленый бонус)
   - **Всего: $20**

## Настройки

```python
MLM_PARTNER_PRICE = 20.0    # Цена за статус партнера
MLM_YELLOW_BONUS = 10.0     # Желтый бонус
MLM_GREEN_BONUS = 10.0      # Зеленый бонус
```

## Отличия от сервера $100

- Сервер $100: сложная система зеленых/красных бонусов
- Сервер $20: простая система - фиксированные $10 желтый + $10 зеленый за каждого партнера
