# MLM Server $20

MLM сервер с логикой $20.

## Логика бонусов

При регистрации нового партнера (оплата $20):
- **$10** - Желтый бонус рефереру
- **$10** - Зеленый бонус рефереру

Итого: реферер получает **$20** при регистрации каждого нового партнера.

## Настройки

- `MLM_PARTNER_PRICE = 20.0` - цена за статус партнера
- `MLM_YELLOW_BONUS = 10.0` - желтый бонус
- `MLM_GREEN_BONUS = 10.0` - зеленый бонус
