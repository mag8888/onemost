# MLM Server $30

MLM сервер с логикой $30.

## Логика бонусов

При регистрации нового партнера (оплата $30):
- **$15** - Желтый бонус рефереру
- **$15** - Зеленый бонус рефереру

Итого: реферер получает **$30** при регистрации каждого нового партнера.

## Настройки

- `MLM_PARTNER_PRICE = 30.0` - цена за статус партнера
- `MLM_YELLOW_BONUS = 15.0` - желтый бонус
- `MLM_GREEN_BONUS = 15.0` - зеленый бонус
