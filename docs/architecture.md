# Архитектура системы

## Обзор

Микро-модульная система состоит из:

1. **Центральный сервер (Core Server)** - единая точка хранения данных
2. **MLM серверы** - независимые серверы для обработки реферальной системы

## Центральный сервер

### Компоненты:

- **Users** - управление пользователями
- **Wallet** - баланс и кошелек
- **Bot** - Telegram бот
- **Web** - веб-интерфейс
- **API Gateway** - API для MLM серверов

### База данных:

- PostgreSQL - основная БД
- Хранит всех пользователей, транзакции, реферальные связи

## MLM серверы

### Компоненты:

- **MLM** - логика MLM системы
- **Referrals** - реферальная структура
- **API Client** - клиент для связи с Core

### База данных:

- SQLite - локальная БД для структуры
- Хранит только локальную MLM структуру (узлы, бонусы)

## Коммуникация

### API между серверами:

```
MLM Server -> Core Server API
- GET /api/users/{id}/ - получить пользователя
- POST /api/users/ - создать пользователя
- POST /api/wallet/{id}/add/ - добавить баланс
- POST /api/referrals/register/ - зарегистрировать реферала
```

### Аутентификация:

- Bearer Token (API Key) для MLM серверов
- Каждый MLM сервер имеет свой уникальный ключ

## MLM Алгоритм

1. Регистрация пользователя через Core
2. MLM сервер создает локальный узел
3. При оплате $100 - статус меняется на "партнер"
4. Начисление бонусов:
   - Зеленый бонус 1: $100 за первого партнера
   - Зеленый бонус 2: $50 за второго партнера
   - Красный бонус: $50 первому партнеру при привлечении 2-го и 3-го
5. При 3 партнерах - повышение ранга (ПУ1, ПУ2, ...)

## Масштабирование

- Можно добавлять новые MLM серверы
- Каждый сервер работает независимо
- Все данные пользователей в Core
- MLM серверы синхронизируются через API
