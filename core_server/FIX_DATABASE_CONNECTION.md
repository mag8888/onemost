# Исправление ошибки подключения к базе данных

## Проблема

Ошибка:
```
connection to server at "localhost" (127.0.0.1), port 5432 failed: Connection refused
```

Это означает, что Django пытается подключиться к `localhost` вместо Railway PostgreSQL.

## Причина

Переменная `DATABASE_URL` не установлена в сервисе "onemost" в Railway.

## Решение

### Шаг 1: Добавить DATABASE_URL через Reference

1. Откройте проект **"onemost"** в Railway
2. Откройте сервис **"onemost"** (основной сервер)
3. Перейдите на вкладку **"Variables"**
4. Нажмите **"+ New Variable"** → **"Add Reference"**
5. Выберите сервис **"Postgres"** (или как называется ваш PostgreSQL сервис)
6. Выберите переменную **"DATABASE_URL"**
7. Нажмите **"Add"**

### Шаг 2: Проверить переменную

После добавления Reference, в списке переменных должна появиться:
- `DATABASE_URL` с иконкой PostgreSQL и значением типа `postgresql://...`

### Шаг 3: Перезапустить сервис

1. Нажмите **"Redeploy"** или перезапустите сервис "onemost"
2. Проверьте логи - должно появиться:
   ```
   DATABASE_URL found: postgresql://...
   Database configured successfully. Host: ...
   ```
3. Миграции должны выполниться успешно

## Альтернатива: Добавить вручную (если Reference не работает)

1. Откройте сервис **"Postgres"** в Railway
2. Перейдите в **"Variables"**
3. Найдите `DATABASE_URL`
4. Скопируйте его значение (нажмите на значок глаза, чтобы показать)
5. В сервисе **"onemost"** добавьте переменную:
   - **VARIABLE_NAME**: `DATABASE_URL`
   - **VALUE**: вставьте скопированное значение
6. Сохраните и перезапустите

## Проверка

После добавления `DATABASE_URL`:
- ✅ Django должен подключиться к Railway PostgreSQL
- ✅ Миграции должны выполниться успешно
- ✅ В логах должно быть: "Database configured successfully"
- ✅ Сервис "onemost" должен запуститься без ошибок

## Важно!

- ✅ **Используйте Reference** - это автоматически обновит переменную при изменении БД
- ✅ **Не используйте localhost** - Railway использует внутренние хосты
- ✅ **Проверьте логи** - там будет видно, какая конфигурация используется
