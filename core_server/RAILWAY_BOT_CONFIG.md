# Конфигурация Railway для бота

## Файл railway.json для бота

Для сервиса бота нужно использовать команду запуска бота.

### Вариант 1: Использовать railway_bot.json

Если Railway поддерживает разные конфигурации, можно использовать `railway_bot.json`.

### Вариант 2: Изменить в настройках Railway (рекомендуется)

1. Откройте сервис **"onemost-bot"** в Railway
2. Перейдите в **"Settings"** → **"Deploy"**
3. В поле **"Custom Start Command"** измените на:

```bash
python manage.py migrate && python manage.py run_telegram_bot
```

4. Сохраните

### Вариант 3: Использовать Procfile

Railway может использовать Procfile. Убедитесь, что в настройках сервиса указан процесс `bot`.

## Проверка

После изменения команды:
- Railway перезапустит сервис
- В логах должно появиться сообщение о запуске бота
- Бот должен начать отвечать на команды
