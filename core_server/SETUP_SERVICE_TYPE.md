# Настройка SERVICE_TYPE для разных сервисов

## Решение через переменную окружения

Создан универсальный скрипт `start.sh`, который определяет, какой сервис запускать, по переменной `SERVICE_TYPE`.

## Настройка в Railway

### Шаг 1: Сервис "onemost" (веб-сервер)

1. Откройте сервис **"onemost"** в Railway
2. Перейдите в **"Variables"**
3. Добавьте переменную:
   - **VARIABLE_NAME**: `SERVICE_TYPE`
   - **VALUE**: `web`
4. Сохраните

### Шаг 2: Сервис "onemost-bot" (бот)

1. Откройте сервис **"onemost-bot"** в Railway
2. Перейдите в **"Variables"**
3. Добавьте переменную:
   - **VARIABLE_NAME**: `SERVICE_TYPE`
   - **VALUE**: `bot`
4. Сохраните

## Как это работает

Скрипт `start.sh` проверяет переменную `SERVICE_TYPE`:
- Если `SERVICE_TYPE=bot` → запускает бота (`python manage.py run_telegram_bot`)
- Если `SERVICE_TYPE=web` или не установлена → запускает веб-сервер (`python manage.py runserver`)

## После настройки

1. Railway автоматически перезапустит сервисы
2. Каждый сервис запустит соответствующую команду
3. Проверьте логи:
   - **"onemost"** → должен запустить веб-сервер
   - **"onemost-bot"** → должен запустить бота

## Важно!

- ✅ Оба сервиса используют один `railway.json` с командой `bash start.sh`
- ✅ Переменная `SERVICE_TYPE` определяет, что запускать
- ✅ Не нужно переопределять Start Command в Railway UI
