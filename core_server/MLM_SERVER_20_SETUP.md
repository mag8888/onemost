# Настройка MLM сервера $20

## Нужен ли отдельный сервер?

**Да, нужен отдельный сервер для MLM логики $20.**

## Архитектура

У вас должно быть:
1. **Центральный сервер (core_server)** - уже настроен
   - Хранит пользователей, балансы, кошельки
   - Telegram бот
   - Веб-интерфейс

2. **MLM сервер $100** - должен быть в ветке `3/100`
   - Обрабатывает MLM логику для программы $100

3. **MLM сервер $20** - должен быть в ветке `3/20`
   - Обрабатывает MLM логику для программы $20
   - Желтый бонус: $10
   - Зеленый бонус: $10

## Настройка MLM сервера $20 на Railway

### Шаг 1: Создать новый сервис в Railway

1. В Railway создайте новый проект или используйте существующий
2. Нажмите **"New Service"** → **"GitHub Repo"**
3. Выберите репозиторий `mag8888/onemost`
4. Выберите ветку **`3/20`**
5. В настройках:
   - **Service Name**: `mlm-server-20`
   - **Root Directory**: `mlm_server_20` (или как называется директория)

### Шаг 2: Настроить переменные окружения

Добавьте переменные:
```
SECRET_KEY=<сгенерируйте>
DEBUG=False
ALLOWED_HOSTS=*.railway.app
DATABASE_PUBLIC_URL=<скопируйте из центрального сервера>
CORE_SERVER_URL=https://onemost-production.up.railway.app
CORE_SERVER_API_KEY=<API ключ для связи с центральным сервером>
MLM_PARTNER_PRICE=20.0
MLM_YELLOW_BONUS=10.0
MLM_GREEN_BONUS=10.0
```

### Шаг 3: Настроить Start Command

**Start Command:**
```bash
python manage.py migrate && python manage.py runserver
```

## Проверка

После настройки:
- MLM сервер $20 должен запуститься
- Должен подключиться к центральному серверу
- Бот должен работать с обеими программами

## Важно!

- ✅ Каждый MLM сервер - отдельный сервис в Railway
- ✅ Все серверы используют одну базу данных (через DATABASE_PUBLIC_URL)
- ✅ Центральный сервер координирует работу всех MLM серверов
